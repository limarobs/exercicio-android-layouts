# Exercício Android: Tipos de Layout

Projeto desenvolvido em aula para praticar a criação de telas no Android com Kotlin.

O aplicativo apresenta uma tela de login e, ao tocar em **Login**, abre um menu com exemplos dos seguintes layouts:

- `ConstraintLayout`
- `RelativeLayout`
- `TableLayout`
- `LinearLayout`

## Tecnologias

- Kotlin
- Android SDK
- AndroidX
- Material Components

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Execute o app em um emulador ou dispositivo Android com API 31 ou superior.

## Observação

Este é um exercício acadêmico feito em aula.
